# Angular Interview Project

## Getting Started

To start the development server, run these commands in your terminal:

```bash
npm install
npm start
```

And you can view the app preview at:
[Preview App]({URL})

## Commands
- `npm start`: Start the development server.
- `npm run build`: Build the app.
- `npm test`: Run the unit tests (Vitest).
- `npm run lint`: Lint the code (ESLint).
- `npx ng generate component <name>`: Generate a component (also works for services, pipes, directives, guards, etc.).

## Project Structure
- `src/app/`: This is where you will write your Angular components, services and logic.
- `src/app/app.routes.ts`: Add your routes here.
- `package.json`: You can add any necessary third-party dependencies here.
